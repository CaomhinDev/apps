# Apps portal

One static page linking to every app in `~/projects/Apps`. No JavaScript, no
build step: open `index.html` directly, or host the folder anywhere.

To add an app: copy its icon into `icons/`, add a `<li>` card in `index.html`,
and give the card an `id` with a `--tint` colour in `styles.css`.
